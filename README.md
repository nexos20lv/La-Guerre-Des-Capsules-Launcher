## 📖 Présentation

Le **LGDC Launcher** est l'application client qui gère l'installation et la mise à jour automatique du jeu **La Guerre Des Capsules**. Il communique directement avec le serveur de téléchargement (**La-Guerre-Des-Capsules-DL**) pour vérifier les numéros de version, télécharger les derniers binaires et lancer le jeu en un clic.

---

## ✨ Fonctionnalités

- 🔄 **Mise à Jour Automatique :** Détection des patchs et téléchargement transparent des nouvelles versions du jeu.
- ⚡ **Lancement Instantané :** Démarre directement l'exécutable Godot compilé.
- 📢 **Flux d'Actualités :** Affiche les dernières notes de mise à jour (changelogs) et annonces de la communauté.
- 🎨 **Interface Graphique Élégante :** Design sobre aux couleurs de l'univers du jeu.

---

## 🛠️ Lancement en Développement

```bash
# Installer les dépendances
npm install

# Lancer l'application en mode développement
npm start
```
